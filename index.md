# geosR

geosR is an R package with helpers for geostatistical analysis, spatial
interpolation, and preliminary resource calculations. It wraps functions
from `gstat`, `sf`, `terra`, and `tmap`.

The package is in development (`0.0.0.9000`). Check units, coordinate
systems, and calculation assumptions before using outputs in a study.

## Install

Install R and the system libraries required by `sf` and `terra` on your
platform (GDAL, GEOS, and PROJ where applicable). Then run:

``` r

install.packages("remotes")
remotes::install_github("ghoziankarami/geosR", build_vignettes = FALSE)
library(geosR)
```

Building vignettes is optional and also requires `knitr`, `rmarkdown`,
and Pandoc. Use `build_vignettes = TRUE` once those tools are installed.

## Functions

| Functions | Purpose |
|----|----|
| [`fit_var()`](https://ghoziankarami.github.io/geosR/reference/fit_var.md), [`est_krige()`](https://ghoziankarami.github.io/geosR/reference/est_krige.md) | Variogram fitting and kriging. |
| [`calc_res()`](https://ghoziankarami.github.io/geosR/reference/calc_res.md), [`ev_rest()`](https://ghoziankarami.github.io/geosR/reference/ev_rest.md) | Resource calculations and recovery adjustments. |
| [`plot_res()`](https://ghoziankarami.github.io/geosR/reference/plot_res.md) | Spatial maps using tmap. |
| [`nscore()`](https://ghoziankarami.github.io/geosR/reference/nscore.md), [`backtr()`](https://ghoziankarami.github.io/geosR/reference/backtr.md), [`no_outlier()`](https://ghoziankarami.github.io/geosR/reference/no_outlier.md) | Distribution transformations and outlier handling. |

Consult each function’s help page for argument names and units:

``` r

help("fit_var", package = "geosR")
help("calc_res", package = "geosR")
```

[Tutorials and function
reference](https://ghoziankarami.github.io/geosR/) are published through
pkgdown. The vignette source is in `vignettes/`.

## Repository

| `man/`               | Function help files generated by roxygen2.   |
| `vignettes/`         | Tutorial sources.                            |
| `analysis/`          | Worked analyses and supporting manuscripts.  |
| `.github/workflows/` | Documentation build and contribution checks. |

For local package checks:

``` bash
git clone https://github.com/ghoziankarami/geosR.git
R CMD build geosR
R CMD check --no-manual geosR_0.0.0.9000.tar.gz
```

This package assists calculations; its outputs are not a certified
resource or reserve statement. Independent geological and statistical
review is required.

## Automated package checks

The `R CMD check` workflow installs the package and its dependencies,
builds the vignette, and runs the package checks on Linux. Base-R tests
in `tests/known-answers.R` cover normal scores, IQR filtering and
reconciliation arithmetic using small deterministic inputs. The separate
pkgdown workflow builds the documentation site; it does not replace
package checks.

To reproduce the package check locally, use the R CMD build/check
commands above. Broader kriging, grid geometry, units and cross-platform
validation remain additional work; passing these initial tests does not
establish scientific validity for every workflow.
